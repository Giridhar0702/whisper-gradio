Whisper Speech-to-Text (ASR) Application

This project is a local Speech-to-Text (ASR) web application built using OpenAI Whisper and Gradio.
It converts spoken audio into text and runs completely on the local system without using any external APIs.

----------------------------------------------------------------

Tech Used

- Python
- OpenAI Whisper
- Gradio
- FFmpeg

----------------------------------------------------------------

Model Type

- Model: Whisper
- Type: Automatic Speech Recognition (ASR)
- Architecture: Transformer-based deep learning model
- Execution: Runs locally (offline after model download)

----------------------------------------------------------------

Use Cases

- Voice notes transcription
- Meeting and lecture transcription
- Speech-to-text applications
- Accessibility tools
- Language learning and analysis

----------------------------------------------------------------

Requirements

Make sure the following are installed before running the project:

Python
- Python version 3.9 or above

Check:
```bash
python --version
```
------------------------------------------------------------------
1.Create a virtual environment
```bash
    python -m venv venv
```
2.Activate the virtual environment
```bash
    venv\Scripts\activate 
```
3.Install required dependencies
```bash
    pip install -r requirements.txt
```
4.Run the application
```bash
    python app.py
```
